# BADPLAYZ

Personal cyberpunk portfolio for [@EdvinsG](https://x.com/EdvinsG) — crypto ambassador.

Currently repping: **Yellow**, **Midnight Network**, **GalaxySwap**.

## Stack

- Plain HTML + CSS (no build step)
- Google Fonts: Orbitron, JetBrains Mono
- Pure CSS effects: glitch, neon glow, scanlines, animated grid

## Run locally

Just open `index.html` in your browser. That's it.

```bash
# or, if you want a tiny local server:
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Deploy (free, 1-click)

### Option A — Vercel (recommended)
1. Go to [vercel.com](https://vercel.com) and sign in with GitHub
2. Click **Add New → Project**
3. Pick the `Badplayz` repo and click **Deploy**
4. Done. You get a URL like `badplayz.vercel.app`

### Option B — GitHub Pages
1. Go to repo **Settings → Pages**
2. Under **Source**, pick branch `main` and folder `/ (root)`
3. Save. Your site goes live at `https://edvins99.github.io/Badplayz/`
